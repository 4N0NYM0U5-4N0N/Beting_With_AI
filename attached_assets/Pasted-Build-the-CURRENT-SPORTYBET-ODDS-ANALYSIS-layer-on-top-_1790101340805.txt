# 6. BOOKMAKER PROBABILITY

For each fixture calculate:

```text
raw_implied_probability = 1 / odds
```

For the three 1X2 outcomes calculate:

```text
overround = P(H) + P(D) + P(A)
```

Then calculate normalized market probabilities:

```text
normalized_probability = raw_implied_probability / overround
```

Report both:

* raw implied probability
* normalized market probability

Do not confuse these two quantities.
