================================

This is the most important part.

Build every pre-match feature from epl_historical_clean.csv.

For every match, the feature calculation must use ONLY matches that occurred strictly before that match.

Never use information from the match currently being predicted.

Never use future matches.

Build at minimum:

TEAM FORM

* matches played previously
* points per match
* wins/draws/losses
* goals scored
* goals conceded
* goal difference

ROLLING FORM

5-match and 10-match:

* goals scored
* goals conceded
* goal difference
* points
* shots
* shots on target
* corners
* yellow cards

HOME/AWAY FORM

For the home team:

* previous overall form
* previous home-only form

For the away team:

* previous overall form
* previous away-only form

HEAD-TO-HEAD

Only include H2H information from matches that occurred before the current fixture.

Do not use future H2H results.

LEAGUE POSITION

If reconstructing league position, calculate the table using only results available before the match.

Never use the final season table.

SAMPLE SIZE

For every rolling feature, also track how many historical matches were actually available.

Do not pretend that a team with only 2 previous matches has a genuine 5-match history.

10. PROBABILITY HANDLING
========================

For decimal odds:

implied_probability = 1 / odds

Calculate bookmaker overround:

sum(implied probabilities)

Also calculate normalized implied probabilities where appropriate.

Never confuse bookmaker implied probability with a true probability.

For every model produce:

* predicted probability
* actual result
* log loss
* Brier score
* calibration information
